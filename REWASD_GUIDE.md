# DuneShark on a controller (reWASD)

DuneShark's shortcuts are keyboard combos, so any controller button can trigger them through **reWASD**
(the free version is enough). DuneShark doesn't need to know about the controller at all.

## Default shortcuts (change them in `hotkeys.json`, in the DuneShark folder)

| Combo | What it does |
|---|---|
| Ctrl+Alt+B | Instant build on/off |
| Ctrl+Alt+P | Infinite power on/off |
| Ctrl+Alt+PageUp | Suspensor speed +0.5 |
| Ctrl+Alt+PageDown | Suspensor speed -0.5 |
| Ctrl+Alt+D | Daytime (10:00) |
| Ctrl+Alt+N | Night (22:00) |
| Ctrl+Alt+H | Refill health |
| Ctrl+Alt+W | Refill water |
| Ctrl+Alt+U | Unstuck (nearest safe spot) |
| Ctrl+Alt+G | God mode on/off |
| Ctrl+Alt+S | Finish story step (press twice) |
| Ctrl+Alt+X | Finish side step (press twice) |
| Ctrl+Alt+1 | Build Ready Kit |
| Ctrl+Alt+2 | Basic Survival Kit |
| Ctrl+Alt+Home | Show DuneShark on top of the game / hide it again |
| Ctrl+Alt+C | Instant ability cooldowns on/off |

## Mapping a button in reWASD

1. Open reWASD and select your controller.
2. Pick a button you don't use in Dune. A **shift/layer** works well: for example hold **View (Back)** as a
   shift, then use A/B/X/Y and the D-pad for DuneShark.
3. Assign it a **keyboard mapping** with the combo from the table, for example `Ctrl + Alt + P`.
4. Apply the config. Press the button in game: a small notice appears at the bottom of the screen.

Tip: suggested layer with View held: D-pad Up/Down = suspensor faster/slower, A = instant build, B = unstuck,
X = infinite power, Y = refill health.
